# Replit and GitHub handoff notes

This archive contains the application source prepared for a private GitHub repository. The current app is a desktop assistant (PyQt UI, microphone/camera, local screen and computer control); it is not deployable as-is as a hosted Replit web app because a hosted process cannot access your personal computer's peripherals or desktop session. A separate web adaptation would be needed for a hosted Replit deployment.

Sensitive/local files intentionally omitted: browser profile data, runtime memory, API/login configuration, phone pairing settings, and local TLS certificate/private-key files. Configure secrets locally or through Replit Secrets if you later build a hosted web version.

The original README states a Creative Commons Attribution-NonCommercial 4.0 license. Keep its attribution and license terms, and confirm you have the right to publish the source before making the repository public.
